# 内容矩阵运营手册

面向运营人员（非开发者）：从内容创作到发布、评论引流、加企微的完整日常操作流程。

## 一、整体流程一览

```
灵感库（热榜采集/手动录入 → AI 拆解 → 一键仿写）
  → 创作台（AI 起稿 → 合规双审 → 查重 → 提交审核 → 管理员审批）
    → 发布页（选账号/定时 或 加入队列自动占坑 → 自动发布 → 自动首评引流）
      → 评论页（自动采集 → 自动回复暗号）
        → 用户私信暗号 → 智能客服接待 → 留资 → 推送企微活码
          → 漏斗页（四级转化）+ 效果页（作品数据/选题 ROI，反哺选题）
```

日常使用涉及六个页面：**灵感**、**创作**、**发布**、**评论**、**效果**、**漏斗**（导航栏左侧）。

## 二、创作台使用方法

1. 「创作」页 → 新建选题：填主题（如「夏季便携榨汁杯上新」）、卖点（逗号分隔）
2. 选中选题 → 右侧「AI 生成」面板：勾选目标平台（抖音/小红书）、选内容类型（图文/视频脚本）、选**每平台版数**（1-3 版）
3. 点击生成 → 等待 10~30 秒（AI 起稿 + 两轮合规审查），生成结果出现在「版本」列表
4. 每个平台一个版本：标题、正文、话题标签、（视频类另有分镜脚本与封面文案）

### 一稿多版（A/B 测风格）

「每平台版数」选 2-3 时，同一选题会按不同风格各生成一版：**V1 测评风**（真实体验分享）、**V2 提问风**（痛点提问切入）、**V3 清单风**（结构化干货）。版本 Tab 标注 `V2·提问风` 便于区分。

- 用途：同题不同风格各发一部分账号，一周后看「效果」页数据，跑出的风格加大投放
- 同选题的多个变体**不会**互相触发查重拦截（刻意备选，不算同质化）
- 建议同平台同选题最多发 2 个变体，发太多仍是同质化风险

### 编辑辅助四件套（版本编辑器内）

- **标题助手**：标题框旁按钮 → AI 按选题+正文出 10 个候选标题（标注所用公式与爆款潜力评分），点击直接套用
- **关键词埋词**：话题标签框旁按钮 → AI 推荐 8 个品类热搜词并检测当前标题/正文/标签是否已覆盖；未覆盖的可「一键加入标签」（搜索流量入口，优先埋长尾词）
- **预览**：底部「预览」按钮 → 按平台样式渲染当前编辑内容（图文=小红书笔记卡：封面文案+标题+正文+话题+首评气泡；视频=脚本卡：封面+标题+简介+口播脚本），发前自检排版与长度
- **规格实时计数**：标题/正文字数与话题标签数实时显示 `当前/上限`，超限变红（与平台硬规格一致，超限内容发布必被截断）

> 品牌语气：管理员在「设置 → 品牌语气」填写品牌风格指南后，AI 创作全矩阵内容自动统一调性（自称/口癖/禁忌），立即生效。

### 合规报告怎么看

每个版本右上角有合规状态：

- **通过**（绿）：可直接进入发布环节
- **待人工**（黄）：AI 自动改写 2 轮后仍有疑点，报告里列出**命中词**与**修改建议**，手动改完后点「复检」，通过即可
- 常见命中：广告法极限词（最/第一/国家级）、引流词（微信/加 V/私信联系方式——**公开内容绝对禁止**）

> 注意：合规拦截不是找麻烦。公开内容带联系方式是平台封号高危行为，系统宁可误杀。

### 素材库

「创作」页可上传图片/视频素材（素材库），生成图文版本后可将素材合成短视频（图文成片：自动加字幕、可选配音/背景音乐）。

### 查重与审批（发布前两道闸）

- **查重 badge**：每个版本生成后自动与同平台近 90 天内容对比（SimHash）。绿色「查重通过」可放心发；黄色（70%+）建议差异化改写；红色（90%+）发布时会被拦截并要求二次确认——矩阵账号发高相似内容是限流主因，非必要不强行发
- **审批流**：版本全部合规通过后点「提交审核」→ 管理员在创作台「审批通过/驳回」（驳回必填原因，驳回后修改可重新提交）。**未审批通过的内容无法创建发布任务**，这是硬性约束

### 首评引流话术（强烈推荐配置）

版本编辑器底部有「首评引流话术」：发布成功后系统延迟 1-3 分钟自动以本账号发一条顶层评论，如 `需要报价单的宝子私信我回复【{code}】`（`{code}` 自动替换为当前暗号）。

- 为什么有效：评论区置顶位置曝光最高，把「看内容 → 私信」的转化路径缩到最短
- 红线：首评同样**禁止任何联系方式**（引流词零容忍守卫会拦截），只能引导私信 + 暗号
- 首评占用账号评论日限额（与回复共用额度），日限额留有余量

## 三、发布策略建议

「发布」页创建发布任务：选内容版本 → 勾选账号（可多选矩阵账号）→ 设定时间，或点「加入队列」让系统按账号时段位自动占坑。

### 发布日历与队列

- **日历视图**：发布页右上角切「日历」，整月排期一目了然；「待发布」任务可直接**拖拽到其他日期**改期（保留原时刻）
- **队列模式**：账号页给账号配置「队列时段位」（如 `12:00,19:30`，北京时间）后，发布弹窗点「加入队列」自动占下一个空闲坑位；同一时段 ±30 分钟内不会撞车，当日额度满了自动排次日
- **最佳时段推荐**：发布弹窗选中单个账号时显示推荐时段——该账号历史播放数据足够时按真实数据推荐，否则用平台黄金时段默认值

### 频次与时段

### 频次与时段

| 平台 | 建议频次 | 建议时段 |
|---|---|---|
| 抖音 | 每号每天 1~2 条 | 12:00-13:00、18:00-22:00 |
| 小红书 | 每号每天 ≤1 条（RPA 硬上限 3 条，间隔 30~90 分钟） | 10:00-11:00、20:00-22:00 |

- **账号轮换**：同一内容不要同一天发所有账号，错开 1~2 天，降低同质化判重风险
- 超过账号日限额的任务会自动推迟到次日 9 点后，无需人工处理
- 发布后「发布」页可见作品链接；小红书经 RPA 发布，链接通常在 Worker 执行后 1 分钟内回传

### 导出发布包

需要人工手动发布时（如账号养号期），可点「导出」下载该任务的文案+素材打包，线下发布。

## 四、评论规则与暗号体系

「评论」页两个 Tab：

### 评论列表

- 默认看「待处理」：差评/广告/系统拿不准的评论都在这里，人工回复或跳过
- 已自动回复的评论可回看回复内容
- 回复框输入的内容同样过合规检查，**禁止联系方式**（会被拦截）

### 回复规则

规则 = 命中条件（意图/关键词）+ 回复模板 + 暗号：

- **意图**：咨询 / 问价 / 好评（差评和广告永远不自动回复）
- **关键词**：如「多少钱」「怎么买」，逗号分隔；留空则只按意图匹配
- **回复模板**：多条用 `|` 分隔，随机选一条；`{code}` 会被替换成暗号
- **暗号**：一个字词（如「价格」），用户私信这个词即完成归因。**暗号要口语、不敏感**，不要用「微信」「加好友」这类词

示例规则：意图=问价，关键词=多少钱,价格 → 模板「价格私您啦，回复{code}有惊喜」→ 暗号「价格」。

> 全局开关：页面右上角「自动回复」开关关闭后，所有评论只采集分类、不自动回复（全部转人工）。设置页也有同样的总开关（管理员）。

## 五、漏斗看板读数

「漏斗」页看四级转化（近 7/14/30 天可切换）：

| 层级 | 含义 | 健康参考 |
|---|---|---|
| 评论互动 | 采集到的评论数 | 随发布量增长 |
| 私信暗号 | 私信中命中暗号的人数 | 评论→私信 ≥5% 算正常 |
| 留资推送 | AI 推送企微活码的人数 | 私信→留资 30%+ |
| 加企微 | 实际扫码加粉人数 | 留资→加微 50%+ |

- 下方「按平台」「按账号」表格用于横向对比：哪个账号的哪一级转化掉了，就针对性优化那一级的话术/内容
- 「事件明细」可追溯每一次状态跃迁的来源（暗号、客户、账号）

## 六、效果分析与灵感库（数据反哺创作）

### 效果页

「效果」页三个 Tab，数据每 4 小时自动回采（发布后 7 天内持续跟踪）：

- **作品排行**：按播放/点赞/评论/分享/收藏排序，支持平台与时间窗筛选；点「趋势」看单作品增长曲线（判断是长尾款还是爆发款）
- **选题 ROI**：按选题聚合所有平台版本的播放数据 + 引流漏斗（评论/私信/留资/加微）。**留资和加微列是核心**——播放高但不带资的选题要少做，播放一般但加微高的选题要批量复制
- **账号对比**：按账号聚合发布数/总播放/点赞/评论/留资/加微 + 发布成功率 + 健康度 + 粉丝数。用来回答「哪个账号值得加码、哪个账号该淘汰或换内容方向」；同分组账号横向对比最能看出运营水平差异

### 灵感库（爆款仿写）

「灵感」页沉淀对标爆款，两个来源：

1. **手动录入**：刷到对标爆款，粘贴标题 + 链接 + 正文
2. **热榜采集**（技术执行）：运行 `hot_collect_worker.py --platform 平台 --keyword 品类词`，自动按热度采集 TOP 内容入库（按链接去重，可每天定时跑）

使用链路：**AI 拆解**（自动提炼标题公式/内容结构/开头钩子/卖点切入）→ **一键仿写**（自动创建仿写草稿并跳转创作台）→ 正常走生成/审批/发布流程。

> 仿写是学方法论不是抄文案：系统会把拆解结论注入创作提示词，并要求围绕你的选题原创表达；生成后查重闸也会拦住与原文（或与你历史内容）过于相似的版本。

## 七、账号健康度与批量管理

### 健康度看板

「账号」页每个账号卡片左上角有健康点：**绿** = 正常，**黄** = 预警，**红** = 异常（鼠标悬浮看具体问题与健康分）。存在红色账号时页面顶部出现红色预警条。

四类健康信号：

| 信号 | 黄（预警） | 红（异常） |
|---|---|---|
| 账号状态 | — | 授权过期 / 已停用 |
| 授权有效期（API 账号） | 约剩 ≤7 天（卡片显示「N 天后过期」橙色倒计时） | 已过期需重新授权 |
| RPA Worker（RPA 账号） | 登录过期 / 页面改版 | Worker 无心跳/掉线 |
| 发布成功率（近 7 天） | 低于 50%（≥3 单样本） | — |

系统每小时自动扫描一遍，问题账号按「每天每问题一次」推送钉钉/企微告警（配置 `ALERT_WEBHOOK_URL` 后生效）。**建议每天开工先扫一眼账号页健康点**——授权临期提前重新授权，不要等过期掉量。

> 口径说明：盯的是 refresh_token 有效期（约 30 天）；access_token 到期系统会自动刷新，无需人工干预。

### 分组与批量导入

- **分组筛选**：账号页顶部分组 chips（含组内计数），按业务线（如「美妆线」）快速过滤；效果页「账号对比」可配合分组看
- **批量导入**：账号页「批量导入」→ 按 `平台,名称,接入方式,Worker标识,分组` 每行一个粘贴（RPA 账号必须填 Worker 标识）→ 逐行校验，失败行给原因不阻断其他行。导入后 API 账号仍需逐个走 OAuth 授权、RPA 账号需对应 Worker 在线
- **画像展示**：账号卡片显示粉丝数/作品数/获赞数（每 4 小时随数据回采自动刷新）

## 八、常见风控信号与处置

| 信号 | 可能原因 | 处置 |
|---|---|---|
| 账号页出现红色健康预警条 | 授权过期 / Worker 掉线 / 账号停用 | 点卡片健康点看具体问题，按提示重新授权或重启 Worker |
| 评论自动回复被平台删除 | 回复含敏感词/被举报 | 立即在「评论」页停用该规则，换模板；检查是否误留联系方式 |
| 小红书发布连续失败 | 登录过期或页面改版 | 看「设置 → RPA 通道」Worker 状态：`login_expired` 重新扫码；`selector_mismatch` 联系技术更新选择器 |
| 抖音发布报 token 失效 | 授权过期（30 天） | 「账号」页点「去授权」重新走一遍 OAuth（健康度会提前 7 天预警，别拖到过红） |
| 加粉后没收到欢迎语 | 超过 20 秒窗口或企微限流 | 属正常损耗，企微侧手动补发；持续发生联系技术查日志 |
| 某账号评论→私信转化骤降 | 暗号被平台屏蔽 | 换暗号词（更口语化），观察 3 天 |

**紧急止血**：设置页两个自动化开关（评论自动回复 / 自动发布）可随时一键全停，停后所有动作转人工，排查完再开。
