# 客服使用手册

## 登录与状态

- 工作台地址：http://localhost:5173 ，账号密码由管理员在「设置」页创建
- 点左下角头像切换状态：**接待中**（参与会话分配）/ **休息中**（不分配新会话）

## 对话页（三栏布局）

```
┌──────┬────────────┬──────────────────────┬────────────┐
│ 导航  │  会话列表    │      聊天窗口          │  客户信息栏  │
└──────┴────────────┴──────────────────────┴────────────┘
```

### 会话列表（左）
- 三个分类：**接待中** / **排队中**（AI 转人工的会话在这里，优先处理！）/ **已结束**
- 每条会话显示：平台标识（抖音黑/小红书红）、最后消息、未读数、接待模式（AI/人工/待接）

### 聊天窗口（中）
- **接待模式切换**：顶部按钮「AI 接待中 → 点击转人工」，接管后 AI 静默；也可随时切回 AI
- **AI 消息**：绿色气泡，可展开「参考了 N 条知识」查看引用来源；答得不好点「标记不佳」
- **快捷回复**：输入区「快捷」按钮，点击模板直接填入（模板在设置页维护，都是口语化话术）
- **内部备注**：点「备注」切到黄色模式，内容仅团队可见，不发给用户（适合交接班留言）
- **结束会话**：问题解决后点右上角「结束会话」

### 客户信息栏（右）
- 客户资料、标签（AI 自动打的可删，可手动加）
- 留资信息：AI 提取的手机号/微信
- **关联工单**：当前客户的工单列表，可手动「+ 创建工单」（AI 识别到退货/物流问题时也会自动建单）
- AI 对话小结：长对话自动压缩的摘要，接手时先看它快速了解前情

## 工单页（📋）

- AI 或客服创建的售后/物流工单统一在这里跟进
- 状态流转：**待处理 → 开始处理 → 标记完成**；误关闭可「重新打开」
- 点「查看会话 →」直接跳转到对应客户的对话
- AI 自动建单时页面实时刷新，无需手动刷新

## 接待流程建议

1. 看到「排队中」有会话 → 点进去 → 看 AI 小结和聊天记录
2. 点「转人工」接管 → 回复用户
3. 解决后「结束会话」；暂时搞不定的用内部备注记录进展

## 知识库页

- **知识列表**：维护 FAQ 和文档（详见 rag-guide.md）
- **召回测试台**：验证 AI 能不能答某个问题
- **未命中问题**：AI 答不了的沉淀在这里，补答案一键转 FAQ

## 数据看板

- AI 拦截率：AI 直接回复的比例（越高越好，目标 >70%）
- 转人工率：转人工会话占比（异常升高说明知识库有缺口，去看未命中问题）
- 平均首次响应时长、会话量趋势

## 模拟面板（🧪）

培训/测试用：扮演抖音/小红书用户发消息，体验完整接待流程，不影响真实客户。
